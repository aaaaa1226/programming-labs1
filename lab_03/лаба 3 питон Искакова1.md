Краткие теоретические сведения: 
Модульная архитектура: модуль в Python — это отдельный файл .py. Для подключения используется import или from ... import .... Чтобы код выполнялся только при прямом запуске файла, применяется проверка if __name__ == '__main__':. Системный модуль sys и список sys.argv позволяют передавать скрипту параметры из командной строки.
Базовые структуры данных:
•	Списки (list): упорядоченные изменяемые массивы. Методы: append(), sort(), pop().
•	Кортежи (tuple): упорядоченные неизменяемые последовательности. Используются для защиты данных и возврата нескольких значений из функции.
•	Словари (dict): ассоциативные массивы «ключ: значение». Ключи уникальны.
•	Множества (set): неупорядоченные коллекции уникальных элементов. Поддерживают операции: объединение |, пересечение &, разность -.
Операции срезов: синтаксис [start:stop:step]. start — начало (включительно), stop — конец (не включительно), step — шаг. Отрицательные индексы отсчитываются с конца, а шаг -1 (например, [::-1]) разворачивает последовательность в обратном порядке.
 
Практическая часть
Вариант 7. Физический процесс / инженерное явление:
В процессе работы промышленного сервера АСУ ТП формируется текстовый файл журнала событий. Инженеру по автоматизации требуется оперативно фильтровать аварийные сообщения, извлекать уникальные коды ошибок и просматривать последние записи в обратном хронологическом порядке.
Задачи модуля (variant_mod.py): 
1) extract_errors(log_lines) - фильтрует список текстовых строк, оставляя только записи со статусом 'ERROR';
2) get_error_codes(log_lines) - извлекает множество (set) уникальных кодов ошибок из логов;
3) get_recent_logs(log_lines, count=5) - с помощью среза (-count:] и разворота [:-1] возвращает свежие записи в обратном порядке.Требования к программе main.py:• Считать число запрашиваемых записей count из sys.argv[1) (дефолт 3).• Задать массив логов ПЛК, выделять ошибки и выводить развернутый аварийный дайджест.
Код для программы variant_mod.py:
# variant7_mod.py
# Модуль для анализа логов АСУ ТП

def extract_errors(log_lines):
    """Оставляет только строки с ERROR."""
    errors = []
    for line in log_lines:
        if 'ERROR' in line:
            errors.append(line)
    return errors

def get_error_codes(log_lines):
    """Собирает уникальные коды ошибок в set."""
    codes = set()
    for line in log_lines:
        if 'ERROR' in line:
            code = line.split('ERROR')[1].split(']')[0].strip()
            codes.add(code)
    return codes

def get_recent_logs(log_lines, count=5):
    """Возвращает последние count записей в обратном порядке."""
    return log_lines[-count:][::-1]

if __name__ == '__main__':
    test = ['[INFO] System start',
            '[ERROR 404] Sensor missing',
            '[WARN] Low battery',
            '[ERROR 500] PLC disconnect',
            '[ERROR 404] Sensor missing']
    print(extract_errors(test))
    print(get_error_codes(test))
    print(get_recent_logs(test, 3))

Код для программы mail.py:
# main.py
# Вариант 7. Анализ логов АСУ ТП

import sys
from variant7_mod import extract_errors, get_error_codes, get_recent_logs

if len(sys.argv) > 1:
    count = int(sys.argv[1])
else:
    count = 3

logs = ['[INFO] System start',
        '[ERROR 404] Sensor missing',
        '[WARN] Low battery',
        '[ERROR 500] PLC disconnect',
        '[ERROR 404] Sensor missing']

errors = extract_errors(logs)
codes = get_error_codes(logs)
recent = get_recent_logs(logs, count)

print("=== АНАЛИЗАТОР ЛОГОВ АСУ ТП ===")
print("Аварийные события:", len(errors))
print("Уникальные коды ошибок (set):", codes)
print("Свежие логи (срез [-" + str(count) + ":][::-1]):", recent)
